# CoolKit XZ-02 / 小喷一号

这个板型以官方 `xingzhi-cube-1.54tft-wifi` 为硬件基线，针对 CoolKit XZ-02（ESP32-S3 N16R8）增加了自定义唤醒词和完全本地的人脸识别。

## 隐私边界

数据流只有：

`ESP32-CAM /jpg` → `局域网 HTTP` → `S3 PSRAM 临时 JPEG/RGB` → `本地检测与比对`

- 固件只接受回环、RFC1918、链路本地 IPv4 或 `.local` 主机名，拒绝公网、HTTPS 跳转和带账号密码的 URL。
- JPEG 解码、检测和比对全部在 ESP32-S3 本机完成；只在 PSRAM 保留最近一帧供局域网页面预览，下一帧到达即覆盖，断电即消失。
- `/face` 分区只保存爸爸的人脸特征向量，不保存原始图片。
- 此功能不调用设备协议中的摄像头或 MCP 图像上传路径。

本地人脸模型会让应用超过标准 4 MB OTA 槽位，因此 16 MB Flash
采用一个 6.875 MB 应用分区。此板型的固件升级通过 USB 安装。

## 默认行为

- 唤醒词：`小喷小喷`（模型拼音为 `xiao pen xiao pen`）。
- 唤醒回应：`我在呢`，由设备内置音频本地播放。
- 表情：全屏桌面宠物颜文字，会眨眼、转动视线，并响应高兴、伤心、生气、思考、困倦、惊讶等状态。
- 识别爸爸：只把“爸爸到门口”这一身份事件交给当前 LLM，为丸子即兴生成温暖、诙谐的回家播报。
- 识别其他人：只把“发现陌生人”这一身份事件交给当前 LLM，即兴生成不制造恐慌的警戒提醒。
- 云端不可用或小喷正在对话时，自动播放内置的固定兜底语音；原始照片和人脸特征不会提交给 LLM。
- 摄像头地址：`http://192.168.31.91/jpg`。

## 按键

- 中间键单击：开始/停止对话；开机阶段进入配网。
- 中间键双击：录入一份爸爸的人脸特征。建议在正脸及轻微左右转头时分别录入，共 3–5 份。
- 中间键长按：在屏幕上显示本地管理页面地址。
- 减号键双击：清除全部爸爸人脸特征。
- 加减号单击/长按：保持原有音量控制。

没有爸爸样本时，固件不会把看到的人直接判断为陌生人，而是提示先录入。

## 本地管理页面

设备连接 Wi-Fi 后，在同一局域网的手机或电脑上打开：

`http://设备IP:8080`

当前开发环境中的地址通常是 `http://192.168.31.48:8080`；IP 变化时可长按中间键查看。页面可以查看摄像头连接、最近一帧本地预览、检测到的人脸数、样本数量和当前识别状态，也可以录入或清空爸爸样本。

- 点击录入后会持续等待最多 20 秒，不会因为第一帧无人脸就立即失败；多人入镜、超时、成功和失败都会在页面显示。
- 预览读取识别任务已经抓取到 PSRAM 的最近一帧，不会为了页面额外请求摄像头；JPEG 不写入 Flash、不上传云端。
- 所有请求只接受与设备相同子网的 IPv4 来源。
- 录入和清空使用每次启动随机生成的页面令牌，第三方网页不能直接提交写操作。
- 页面不依赖外部脚本、字体或 CDN，断开互联网也能使用。

页面的“本地语音设置”还可以修改自定义唤醒词拼音、显示文字、检测阈值，以及在“我在呢”和系统提示音之间选择唤醒回应。设置保存在 NVS，重启设备后由 MultiNet 重新加载。对话大模型、角色 Prompt、音色与隐私策略通过本机运行的“小喷 Lite”管理，设备不保存控制台凭据。

## 构建与烧录

使用 ESP-IDF 5.5.2：

```sh
source /Users/ken/workspace/esp32/esp-idf-v5.5.2/export.sh
python scripts/release.py coolkit-xz-02 --name coolkit-xz-02
idf.py -p /dev/cu.usbmodem1101 flash monitor
```

可在 `menuconfig` 的 `CoolKit XZ-02 Local Face Recognition` 菜单中修改摄像头 URL、轮询周期、播报冷却时间和最大样本数。
